# TKA Pancasila Seru — Kelas 6 SD

Web latihan interaktif Pendidikan Pancasila: **7 Bab, 245 soal persis modul** (`D:/!AGY/Soal/asdad.pdf`) + materi kartu + gamifikasi.

- 🎮 Tiap Bab 35 soal: PG, PG kompleks, isian, menjodohkan, benar/salah, uraian
- ⭐ XP + streak + badge per Bab, kunci & pembahasan langsung tiap jawab
- 📱 Fokus HP Android, light-mode cerah, suara bisa dimute, tanpa login (localStorage)
- 🦁 Maskot: Bonar, Memey, Pigey, Sedi, Indi, Manda & Anisa

Live: https://tka-pancasila-interaktif-sekawan.vercel.app

## Kembangin

```bash
npm install
npm run dev
npm run build
vercel deploy --prod --yes .
```
